# DailyTrivia

A MD3 Trivia game. DailyTrivia brings you features like user profiles, leaderboard, and OAuth 2.0 authorization.

## Supported Versions

Android 8.1 ~ 14

## Build
Clone the repo:
```bash
git clone git@github.com:explosion335/DailyTrivia.git
```

Run gradle task with a debug build:
```bash
./gradlew assembledebug
```

Or with a release build:
```bash
./gradlew assemblerelease
```
